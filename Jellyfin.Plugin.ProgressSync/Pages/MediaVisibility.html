Media visibility

Hide selected movies, shows, episodes, albums, or tracks from a user or everyone. Rules use Jellyfin’s blocked-tag access checks, so they apply on the server rather than only in this dashboard.

Scheduled visibility Optionally choose the month-and-day range when an item is visible every year. Outside that range it is hidden. Dates use the Jellyfin server’s local time. For example, set December 1 through December 31 to show Christmas or other seasonal media only in December each year.

Add a hide rule

Browse posters or search by title, then check every item to hide. Selecting a show, season, or album also applies the rule to its child media.
