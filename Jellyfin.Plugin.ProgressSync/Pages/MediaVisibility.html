Media visibility

Hide selected movies, shows, episodes, albums, or tracks from a user or everyone. Rules use Jellyfin’s blocked-tag access checks, so they apply on the server rather than only in this dashboard.

Scheduled visibility Optionally choose the annual date range when an item is visible. Outside that range it is hidden. Dates use the Jellyfin server’s local time. For example, set December 1 through December 31 to show seasonal media only in December.

Add a hide rule

Search for a title, then choose who can see it. Selecting a show, season, or album also applies the rule to its child media.
