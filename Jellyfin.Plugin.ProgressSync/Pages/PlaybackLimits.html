Playback limits

Set how many devices can play at the same time for each user. If playback exceeds the limit, the newest stream or streams receive a stop command. The limit is rechecked as playback continues.

Choose a limit per user A limit applies to that user's active playback sessions across their devices.
0 means unlimited Set a user's value to zero to allow any number of concurrent streams.
Choose which stream to stop For each user, stop either their newest or oldest playback session when over the limit.

Limits by user

Choose a whole number from 0 to 100 and which stream to stop. Changes take effect when saved.
